# Contributing

Thanks for helping improve Registration Enhancer.

## Before opening an issue
- Search existing issues first.
- Confirm the issue on a supported Pterodactyl Panel 2.0 build.
- Include the extension version and panel build/commit where relevant.
- Share sanitized logs, reproduction steps, and screenshots when useful.
- Never include credentials, CAPTCHA secret keys, session cookies, or private customer data.

## Bug reports
Include expected behavior, actual behavior, exact reproduction steps, panel/extension versions, browser/device details for UI issues, and sanitized logs.

## Pull requests
- Keep changes focused and explain why they are needed.
- Preserve compatibility with the panel's extension APIs.
- Test desktop and mobile behavior for UI changes.
- Test CAPTCHA success and failure paths for authentication-related changes.
- Never commit secrets, production logs, user data, generated packages, or local environment files.
- Update documentation when settings or behavior change.
- Do not claim a feature or test is complete unless it has actually been verified.

The public repository scaffold is being prepared before the extension source is published. Until source and build instructions are available, coordinate proposed code changes through an issue first.
